# gh auth

Authenticate gh and git with GitHub

**Usage:** `gh auth <command> [flags]`

## Commands
- [`login`](login/) — Log in to a GitHub account
- [`logout`](logout/) — Log out of a GitHub account
- [`refresh`](refresh/) — Refresh stored authentication credentials
- [`setup-git`](setup-git/) — Setup git with GitHub CLI
- [`status`](status/) — Display active account and authentication state on each known GitHub host
- [`switch`](switch/) — Switch active GitHub account
- [`token`](token/) — Print the authentication token gh uses for a hostname and account
