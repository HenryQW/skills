# gh search

Search across all of GitHub.

**Usage:** `gh search <command> [flags]`

## Commands
- [`code`](code/) — Search within code
- [`commits`](commits/) — Search for commits
- [`issues`](issues/) — Search for issues
- [`prs`](prs/) — Search for pull requests
- [`repos`](repos/) — Search for repositories
