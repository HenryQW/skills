# gh gist

Work with GitHub gists.

**Usage:** `gh gist <command> [flags]`

## Commands
- [`clone`](clone/) — Clone a gist locally
- [`create`](create/) — Create a new gist
- [`delete`](delete/) — Delete a gist
- [`edit`](edit/) — Edit one of your gists
- [`list`](list/) — List your gists
- [`rename`](rename/) — Rename a file in a gist
- [`view`](view/) — View a gist
