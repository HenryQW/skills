# gh issue

Work with GitHub issues.

**Usage:** `gh issue <command> [flags]`

## Commands
- [`create`](create/) — Create a new issue
- [`list`](list/) — List issues in a repository
- [`status`](status/) — Show status of relevant issues
- [`close`](close/) — Close issue
- [`comment`](comment/) — Add a comment to an issue
- [`delete`](delete/) — Delete issue
- [`develop`](develop/) — Manage linked branches for an issue
- [`edit`](edit/) — Edit issues
- [`lock`](lock/) — Lock issue conversation
- [`pin`](pin/) — Pin an issue
- [`reopen`](reopen/) — Reopen issue
- [`transfer`](transfer/) — Transfer issue to another repository
- [`unlock`](unlock/) — Unlock issue conversation
- [`unpin`](unpin/) — Unpin an issue
- [`view`](view/) — View an issue
