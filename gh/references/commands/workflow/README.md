# gh workflow

List, view, and run workflows in GitHub Actions.

**Usage:** `gh workflow <command> [flags]`

## Commands
- [`disable`](disable/) — Disable a workflow
- [`enable`](enable/) — Enable a workflow
- [`list`](list/) — List workflows
- [`run`](run/) — Run a workflow by creating a workflow_dispatch event
- [`view`](view/) — View the summary of a workflow

## Options
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
