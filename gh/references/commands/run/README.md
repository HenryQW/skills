# gh run

List, view, and watch recent workflow runs from GitHub Actions.

**Usage:** `gh run <command> [flags]`

## Commands
- [`cancel`](cancel/) — Cancel a workflow run
- [`delete`](delete/) — Delete a workflow run
- [`download`](download/) — Download artifacts generated by a workflow run
- [`list`](list/) — List recent workflow runs
- [`rerun`](rerun/) — Rerun a run
- [`view`](view/) — View a summary of a workflow run
- [`watch`](watch/) — Watch a run until it completes, showing its progress

## Options
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
