# gh agent-task

Working with agent tasks in the GitHub CLI is in preview and subject to change without notice.

**Usage:** `gh agent-task <command> [flags]`

**Aliases:** `gh agent-tasks, gh agent, gh agents`

## Commands
- [`create`](create/) — Create an agent task (preview)
- [`list`](list/) — List agent tasks (preview)
- [`view`](view/) — View an agent task session (preview)
