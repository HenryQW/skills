# gh label

Work with GitHub labels.

**Usage:** `gh label <command> [flags]`

## Commands
- [`clone`](clone/) — Clones labels from one repository to another
- [`create`](create/) — Create a new label
- [`delete`](delete/) — Delete a label from a repository
- [`edit`](edit/) — Edit a label
- [`list`](list/) — List labels in a repository

## Options
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
