# gh

Work seamlessly with GitHub from the command line.

**Usage:** `gh <command> <subcommand> [flags]`

## Commands
- [`auth`](auth/) — Authenticate gh and git with GitHub
- [`browse`](browse/) — Open repositories, issues, pull requests, and more in the browser
- [`codespace`](codespace/) — Connect to and manage codespaces
- [`discussion`](discussion/) — Work with GitHub Discussions (preview)
- [`gist`](gist/) — Manage gists
- [`issue`](issue/) — Manage issues
- [`org`](org/) — Manage organizations
- [`pr`](pr/) — Manage pull requests
- [`project`](project/) — Work with GitHub Projects.
- [`release`](release/) — Manage releases
- [`repo`](repo/) — Manage repositories
- [`skill`](skill/) — Install and manage agent skills (preview)
- [`cache`](cache/) — Manage GitHub Actions caches
- [`run`](run/) — View details about workflow runs
- [`workflow`](workflow/) — View details about GitHub Actions workflows
- [`stack`](stack/) — Extension stack
- [`co`](co/) — Alias for "pr checkout"
- [`agent-task`](agent-task/) — Work with agent tasks (preview)
- [`alias`](alias/) — Create command shortcuts
- [`api`](api/) — Make an authenticated GitHub API request
- [`attestation`](attestation/) — Work with artifact attestations
- [`completion`](completion/) — Generate shell completion scripts
- [`config`](config/) — Manage configuration for gh
- [`copilot`](copilot/) — Run the GitHub Copilot CLI (preview)
- [`extension`](extension/) — Manage gh extensions
- [`gpg-key`](gpg-key/) — Manage GPG keys
- [`label`](label/) — Manage labels
- [`licenses`](licenses/) — View third-party license information
- [`preview`](preview/) — Execute previews for gh features
- [`ruleset`](ruleset/) — View info about repo rulesets
- [`search`](search/) — Search for repositories, issues, and pull requests
- [`secret`](secret/) — Manage GitHub secrets
- [`ssh-key`](ssh-key/) — Manage SSH keys
- [`status`](status/) — Print information about relevant issues, pull requests, and notifications across repositories
- [`variable`](variable/) — Manage GitHub Actions variables

## Options
  --version   Show gh version
