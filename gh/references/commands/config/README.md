# gh config

Display or change configuration settings for gh.

**Usage:** `gh config <command> [flags]`

## Commands
- [`clear-cache`](clear-cache/) — Clear the cli cache
- [`get`](get/) — Print the value of a given configuration key
- [`list`](list/) — Print a list of configuration keys and values
- [`set`](set/) — Update configuration with a value for the given key
