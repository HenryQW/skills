# gh repo set-default

This command sets the default remote repository to use when querying the GitHub API for the locally cloned repository.

**Usage:** `gh repo set-default [<repository>] [flags]`

## Options
  -u, --unset   Unset the current default repository
  -v, --view    View the current default repository
