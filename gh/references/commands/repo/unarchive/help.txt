Unarchive a GitHub repository.

With no argument, unarchives the current repository.

USAGE
  gh repo unarchive [<repository>] [flags]

FLAGS
  -y, --yes   Skip the confirmation prompt

INHERITED FLAGS
  --help   Show help for command
