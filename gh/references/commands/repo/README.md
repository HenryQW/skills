# gh repo

Work with GitHub repositories.

**Usage:** `gh repo <command> [flags]`

## Commands
- [`create`](create/) — Create a new repository
- [`list`](list/) — List repositories owned by user or organization
- [`archive`](archive/) — Archive a repository
- [`autolink`](autolink/) — Manage autolink references
- [`clone`](clone/) — Clone a repository locally
- [`delete`](delete/) — Delete a repository
- [`deploy-key`](deploy-key/) — Manage deploy keys in a repository
- [`edit`](edit/) — Edit repository settings
- [`fork`](fork/) — Create a fork of a repository
- [`gitignore`](gitignore/) — List and view available repository gitignore templates
- [`license`](license/) — Explore repository licenses
- [`read-dir`](read-dir/) — List a directory in a repository (preview)
- [`read-file`](read-file/) — Read a file from a repository (preview)
- [`rename`](rename/) — Rename a repository
- [`set-default`](set-default/) — Configure default repository for this directory
- [`sync`](sync/) — Sync a repository
- [`unarchive`](unarchive/) — Unarchive a repository
- [`view`](view/) — View a repository
