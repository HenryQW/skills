# gh skill

Install and manage agent skills from GitHub repositories.

**Usage:** `gh skill <command> [flags]`

**Aliases:** `gh skills`

## Commands
- [`install`](install/) — Install agent skills from a GitHub repository (preview)
- [`list`](list/) — List installed skills (preview)
- [`preview`](preview/) — Preview a skill from a GitHub repository (preview)
- [`publish`](publish/) — Validate and publish skills to a GitHub repository (preview)
- [`search`](search/) — Search for skills across GitHub (preview)
- [`update`](update/) — Update installed skills to their latest versions (preview)
