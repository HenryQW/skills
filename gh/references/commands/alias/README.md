# gh alias

Aliases can be used to make shortcuts for gh commands or to compose multiple commands.

**Usage:** `gh alias <command> [flags]`

## Commands
- [`delete`](delete/) — Delete set aliases
- [`import`](import/) — Import aliases from a YAML file
- [`list`](list/) — List your aliases
- [`set`](set/) — Create a shortcut for a gh command
