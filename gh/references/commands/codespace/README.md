# gh codespace

Connect to and manage codespaces

**Usage:** `gh codespace [flags]`

**Aliases:** `gh cs`

## Commands
- [`code`](code/) — Open a codespace in Visual Studio Code
- [`cp`](cp/) — Copy files between local and remote file systems
- [`create`](create/) — Create a codespace
- [`delete`](delete/) — Delete codespaces
- [`edit`](edit/) — Edit a codespace
- [`jupyter`](jupyter/) — Open a codespace in JupyterLab
- [`list`](list/) — List codespaces
- [`logs`](logs/) — Access codespace logs
- [`ports`](ports/) — List ports in a codespace
- [`rebuild`](rebuild/) — Rebuild a codespace
- [`ssh`](ssh/) — SSH into a codespace
- [`stop`](stop/) — Stop a running codespace
- [`view`](view/) — View details about a codespace
