# gh ruleset

Repository rulesets are a way to define a set of rules that apply to a repository.

**Usage:** `gh ruleset <command> [flags]`

**Aliases:** `gh rs`

## Commands
- [`check`](check/) — View rules that would apply to a given branch
- [`list`](list/) — List rulesets for a repository or organization
- [`view`](view/) — View information about a ruleset
