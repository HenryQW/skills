# gh discussion

Working with discussions in the GitHub CLI is in preview and subject to change without notice.

**Usage:** `gh discussion <command> [flags]`

## Commands
- [`create`](create/) — Create a new discussion (preview)
- [`list`](list/) — List discussions in a repository (preview)
- [`comment`](comment/) — Add, edit, or delete a comment or a reply on a discussion (preview)
- [`edit`](edit/) — Edit a discussion (preview)
- [`view`](view/) — View a discussion (preview)

## Options
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
