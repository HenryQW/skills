# gh secret

Secrets can be set at the repository, or organization level for use in GitHub Actions, Agents, or Dependabot.

**Usage:** `gh secret <command> [flags]`

## Commands
- [`delete`](delete/) — Delete secrets
- [`list`](list/) — List secrets
- [`set`](set/) — Create or update secrets

## Options
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
