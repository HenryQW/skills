# gh extension

GitHub CLI extensions are repositories that provide additional gh commands.

**Usage:** `gh extension [flags]`

**Aliases:** `gh extensions, gh ext`

## Commands
- [`browse`](browse/) — Enter a UI for browsing, adding, and removing extensions
- [`create`](create/) — Create a new extension
- [`exec`](exec/) — Execute an installed extension
- [`install`](install/) — Install a gh extension from a repository
- [`list`](list/) — List installed extension commands
- [`remove`](remove/) — Remove an installed extension
- [`search`](search/) — Search extensions to the GitHub CLI
- [`upgrade`](upgrade/) — Upgrade installed extensions
