Upgrade installed extensions

USAGE
  gh extension upgrade {<name> | --all} [flags]

FLAGS
  --all       Upgrade all extensions
  --dry-run   Only display upgrades
  --force     Force upgrade extension

INHERITED FLAGS
  --help   Show help for command
