# gh pr ready

Mark a pull request as ready for review.

**Usage:** `gh pr ready [<number> | <url> | <branch>] [flags]`

## Options
  --undo   Convert a pull request to "draft"
  -R, --repo [HOST/]OWNER/REPO   Select another repository using the [HOST/]OWNER/REPO format
