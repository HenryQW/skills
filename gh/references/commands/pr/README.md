# gh pr

Work with GitHub pull requests.

**Usage:** `gh pr <command> [flags]`

## Commands
- [`create`](create/) — Create a pull request
- [`list`](list/) — List pull requests in a repository
- [`status`](status/) — Show status of relevant pull requests
- [`checkout`](checkout/) — Check out a pull request in git
- [`checks`](checks/) — Show CI status for a single pull request
- [`close`](close/) — Close a pull request
- [`comment`](comment/) — Add a comment to a pull request
- [`diff`](diff/) — View changes in a pull request
- [`edit`](edit/) — Edit a pull request
- [`lock`](lock/) — Lock pull request conversation
- [`merge`](merge/) — Merge a pull request
- [`ready`](ready/) — Mark a pull request as ready for review
- [`reopen`](reopen/) — Reopen a pull request
- [`revert`](revert/) — Revert a pull request
- [`review`](review/) — Add a review to a pull request
- [`unlock`](unlock/) — Unlock pull request conversation
- [`view`](view/) — View a pull request
